# 4 Dages Weekend

En humoristisk, responsiv kampagneside for Danmarks vigtigste helt uofficielle sag: fire dages weekend.

## Funktioner

- Afstemning med én stemme pr. browser via `localStorage`
- Sjove argumenter, FAQ og en videnskabeligt tvivlsom hyggeberegner
- Responsivt design til mobil og computer
- Tilgængelige knapper, labels og reduceret bevægelse

Åbn `index.html` direkte i en browser for at se siden.
